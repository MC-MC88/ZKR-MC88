## 👋 Bienvenue

ذِكر est une interface qui rassemble des azkar et duas authentiques. Le contenu est classé par catégories : matin, soir, sommeil, etc. Vous pouvez rechercher un texte, suivre vos répétitions avec un compteur, et changer de thème. Les sources sont listées en bas de page.

---

## ✨ Ce que vous trouverez

**Catégories d'azkar.**  
Matin, soir, sommeil, réveil, après la prière, nourriture, etc.

**Recherche instantanée.**  
Filtre les textes et les catégories en temps réel.

**Compteur de répétitions.**  
Chaque carte a un bouton pour compter et une barre de progression.

**Quatre thèmes.**  
Classique, Émeraude, Nuit, Sable.

**Sources documentées.**  
Les références sont fournies en bas de page.

---

## 🧭 Comment ça marche

**1. Choisissez une catégorie.**  
Utilisez les onglets pour naviguer.

**2. Lisez le zikr.**  
Le texte arabe est affiché en grand format.

**3. Comptez vos répétitions.**  
Appuyez sur le bouton « تسبيح » pour incrémenter.

**4. Recherchez si besoin.**  
Tapez dans la barre de recherche pour filtrer.

C'est tout. Aucune connexion n'est requise après chargement.

---

## 🛠️ Petits coups de main

**Les azkar sont-ils authentifiés ?**  
Les sources sont listées en bas de page. Vérifiez toujours auprès des références originales.

**Puis-je changer le thème ?**  
Oui, quatre thèmes disponibles via le bouton en haut à gauche.

**Est-ce que ça marche hors ligne ?**  
Oui, après le premier chargement.

**Comment réinitialiser le compteur ?**  
Il se remet à zéro automatiquement après avoir atteint le nombre maximal.

## 👋 Welcome

ذِكر is an interface that gathers authentic azkar and duas. Content is organized by categories: morning, evening, sleep, etc. You can search for a text, track your repetitions with a counter, and change the theme. Sources are listed at the bottom of the page.

---

## ✨ What you'll find

**Azkar categories.**  
Morning, evening, sleep, waking, after prayer, food, etc.

**Instant search.**  
Filters texts and categories in real time.

**Repetition counter.**  
Each card has a button to count and a progress bar.

**Four themes.**  
Classic, Emerald, Midnight, Sand.

**Documented sources.**  
References are provided at the bottom of the page.

---

## 🧭 How it works

**1. Choose a category.**  
Use the tabs to navigate.

**2. Read the zikr.**  
The Arabic text is displayed in large format.

**3. Count your repetitions.**  
Tap the "تسبيح" button to increment.

**4. Search if needed.**  
Type in the search bar to filter.

That's it. No connection is required after loading.

---

## 🛠️ A little help

**Are the azkar authenticated?**  
Sources are listed at the bottom. Always verify with the original references.

**Can I change the theme?**  
Yes, four themes available via the button at the top left.

**Does it work offline?**  
Yes, after the first load.

**How do I reset the counter?**  
It resets automatically after reaching the maximum count.
